Machine Learning Detection

This dashboard visualizes the performance of our Isolation Forest machine learning model for CAN bus anomaly detection. The model was trained on normal traffic patterns and identifies deviations that may indicate cyberattacks.

Why It Matters: Traditional rule-based detection misses sophisticated attacks that mimic legitimate traffic. ML-based detection catches zero-day attacks, injection attempts, and subtle timing anomalies that bypass signature-based systems. ECU-Level Attack Analysis

This view breaks down anomaly detection by Electronic Control Unit (ECU) and CAN identifier. Each ECU (Engine, Brake, Body Control) sends messages with a unique CAN ID, and attacks often target specific subsystems.

Why It Matters: Identifying which ECUs are under attack helps security teams prioritize response. For example, a DoS attack on the Brake ECU (ID 0x120) is more critical than one targeting the Infotainment system. The visualizations below show attack clustering patterns and which ECUs are most frequently targeted, enabling targeted mitigation and forensic analysis.
